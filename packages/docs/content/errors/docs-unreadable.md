# DocsError Unreadable

Envi cannot read its docs folder, or a page has no valid frontmatter. The npm package of Envi
holds the docs in its `docs` folder. In the Envi repo, the build copies the pages into that folder.

Next action: Reinstall Envi, so that its `docs` folder is complete. In the Envi repo, run `bun run build` first.
