# DocsError NotFound

`envi docs show` or `envi docs path` got a name that no docs page has. A name is the path of a
page without `.md`, such as `errors/vars`. The file name and the docs link of an error work too.

Next action: Run `envi docs list` to see every page, or `envi docs search <words>` to find one.
